# 招商理财助手

一个纯前端的理财截图分析工具：上传理财产品收益率截图，自动识别截图中的数据，计算并展示近期年化收益率、历史净值明细以及每万元每日收益。

## 功能特性

- **截图上传**：支持 PNG / JPG / WEBP 图片，PC 端可拖拽上传，手机端可直接选择相册图片
- **AI 识别**：调用 Gemini Vision（`gemini-3.5-flash-lite`）识别截图中的文字、数字与历史净值表，仅做数据识别，不做分析评价
- **收益率计算**：根据历史单位净值计算最近 7 天、最近 14 天的年化收益率（复利口径：`(nav_end / nav_start)^(365/days) - 1`）
- **历史净值表**：逐行展示日期、单位净值、涨跌幅；自动补齐周末 / 节假日等未公布日期的空行
- **万元收益**：将相邻净值差均摊到间隔天数，计算每万元每日收益，并以绿色背景条形图直观展示收益高低
- **原始数据**：展示 Gemini 返回的完整结构化 JSON，支持一键复制
- **响应式布局**：适配桌面与移动端

## 使用方法

1. 直接用浏览器打开 `index.html`（无需构建、无需本地服务器）
2. 上传一张理财产品收益率 / 历史净值截图
3. 点击「开始识别并分析」，等待识别完成
4. 查看近期收益率、历史净值明细与万元收益，或复制原始 JSON 数据

## 技术说明

- **技术栈**：原生 HTML + CSS + JavaScript，单文件实现，无任何依赖与构建流程
- **API**：通过 OpenAI 兼容接口调用 Gemini 视觉模型

  - 模型：`gemini-3.5-flash-lite`
  - 温度 `0.1`，最大输出 `5000` tokens，要求严格返回 JSON
- **数据流程**：图片经 `FileReader` 转为 Data URL → 发送给模型 → 解析返回 JSON（自动剥离 Markdown 代码块）→ 渲染结果
- **健壮性**：模型返回非 JSON 时自动截取 `{...}` 主体重试解析；识别失败会在页面提示错误信息

## 注意事项

- 图片仅在浏览器本地读取后用于本次分析，不在本地持久化存储
- 识别与计算结果仅供参考，不构成投资建议
